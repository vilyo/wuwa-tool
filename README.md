# 鸣潮工具箱（wuwatool）· 鸣潮唤取记录统计助手

纯本地的《鸣潮》（Wuthering Waves）PC 唤取记录统计工具，支持 Windows 与 macOS。Windows 上一键从客户端本地日志提取官方唤取链接，macOS 上手动粘贴链接导入；按卡池拉取全部记录并永久保存在本机，再用统计 + 趣味评语回答那个问题：这一路抽卡，到底是欧是非。所有统计与存储 100% 在本机完成，不上传任何数据。

## 功能

- **一键获取**（Windows）：自动定位游戏安装目录，从客户端日志提取唤取链接（新版日志加密也能自动识别），游戏运行中也可读取；手动粘贴链接、选择本地日志文件导入作为兜底入口（macOS 上以手动粘贴导入代替）。
- **全量拉取 + 本地合并**：官方接口每池一次返回全量历史；本地按去重键合并、只增不减。官方仅保留约 6 个月记录，更早的历史由本地档案永久保存。
- **五星编年史名册**：时间倒序的五星卡片墙——UP / 歪、超欧 / 超非一眼可读；右栏保底引线（距必得还差几抽、大小保底状态）与高光时刻纪念牌。
- **欧非评价**：本地规则评语 + S–D 评级字母，不调用任何在线服务。
- **记录抽屉**：全量流水，按稀有度 / 卡池筛选，2 万条记录虚拟滚动流畅。
- **备份恢复**：JSON 导出 / 导入，换机重装不丢数据。

## 平台与使用方式

- **Windows 10 / 11 x64**（完整功能）：国服与国际服均支持。从 Releases 下载便携版 zip，解压到任意文件夹，双击 `wuwatool.exe` 直接运行——无需安装、不写注册表；升级时用新 exe 替换旧文件，数据不受影响。
- **macOS**：可自行构建运行（`npm install && npm run tauri dev`）。自动获取依赖 Windows 客户端日志，macOS 上不可用；手动粘贴唤取链接即可导入，统计功能完整。
- 获取记录的前提：在游戏内打开过一次「唤取记录」页面。
- 新抽的记录进入官方接口约有 30 分钟延迟，「刚抽完查不到」是预期行为。
