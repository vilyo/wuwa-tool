# 09: 池页签与联动汇总

**What to build:** 每个池的账各是各的：主画面顶部提供四固定类别页签（角色精准调谐 / 武器精准调谐 / 常驻调谐 / 新手·感恩），同类别含多个卡池 code 时页签内二级切换；官方未来新增的未知池落入动态兜底页签做浅统计。顶部一行汇总指标（总唤取、五星数、平均出货、歪率）随页签联动。

**Blocked by:** 07 统计评语核心、08 五星编年史名册（页签切换作用于名册）。

**Status:** ready-for-agent

- [ ] 四固定类别页签 + 类别内多 code 二级切换；切页签后名册、评语行、详情条整体联动刷新
- [ ] 未知池动态兜底页签：有未知 code 记录时出现，做浅统计，无记录时不占位
- [ ] 顶部汇总指标（总唤取、五星数、平均出货、歪率）随页签联动；歪率仅角色系限定池显示数值
- [ ] 新手·感恩类页签：评级「—」、评语「启程之人」、不计入欧非总评（#07 口径的上屏验证）
- [ ] 武器系页签不显示期望参考线；角色系显示
- [ ] 全部文案使用官方用语「唤取」「调谐」
