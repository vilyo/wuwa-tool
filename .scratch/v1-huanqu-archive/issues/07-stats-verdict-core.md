# 07: 统计评语核心 + 本池评语行

**What to build:** 把记录变成「你是欧是非」的答案：前端 TS 领域模块实现全部统计口径与评语规则（出货抽数、歪判定、保底进度、大小保底、评语档位、程度阈值），主画面顶部出现**本池评语行**——评级菱章字母 + 评语 + 平均出货 + 歪率。这是统计接缝的主票：好测试只断言模块外部行为，全部经伪造端口驱动，不发真实网络请求。

**Blocked by:** 02 粘贴链接导入端到端（有数据可算）、06 头像资产与常驻名单数据（名单文件就位）。

**Status:** ready-for-agent

- [ ] 出货抽数含出货那一抽，按池内时间正序计算；池内最早记录即五星时按 1 计并标「不完整」
- [ ] 歪判定采用常驻名单反向判定（ADR-0002）：名单内 = 歪、名单外 = UP、未知物品标「未知」不计入歪率；歪率仅对角色系限定池（1/8/10/12）计算，武器系限定池（2/9/11/13）必中 UP
- [ ] 保底口径：五星硬保底 80 抽（新手调谐池 5 为 50 抽）、四星 10 抽；大小保底状态 = 上一个角色系限定池五星是否歪
- [ ] 评语档位与评级字母（角色系限定池五星平均出货）：S ≤35 天选之人 / A ≤50 欧洲常驻居民 / B+ ≤62 手气不错 / B ≤70 中规中矩 / C ≤78 玄不救非 / D >78 保底战神；档位边界值（35/50/62/70/78）逐一测试
- [ ] 修正项：歪率 ≥80% 追加「命运的反面宠儿」；出过 ≤10 抽五星追加「十里坡剑圣」式彩蛋；角色系限定池五星 <2 显示「样本不足，多抽点再来」；新手·感恩池不计入欧非总评（评级「—」、评语「启程之人」）
- [ ] 程度阈值：超欧 ≤20 抽、超非 ≥70 抽
- [ ] 主画面评语行上屏：评级菱章 + 评语 + 平均出货 + 歪率，随当前池数据渲染
- [ ] 期望参考线常量：角色系 62 抽（社区口径），武器系 V1 不显示（供 #08/#09 消费）
