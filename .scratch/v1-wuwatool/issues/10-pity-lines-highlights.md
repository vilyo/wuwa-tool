# 10: 进行中卡、保底引线与高光纪念牌

**What to build:** 「距必得还差几抽」永远可见：名册首位是虚线「进行中」卡显示当前垫抽数；右栏三条保底引线（角色精准 / 武器精准 / 角色常驻）带 0–80 刻度与小/大保底标注；下方高光时刻纪念牌纪念极端时刻——旅途总览、最欧、最非、大保底就绪。

**Blocked by:** 07 统计评语核心（保底进度/大小保底计算）、08 五星编年史名册（主画面布局就位）。

**Status:** ready-for-human

- [ ] 名册首位虚线「进行中」卡：当前垫抽数与距必得剩余
- [ ] 右栏三条保底引线（角色精准 / 武器精准 / 角色常驻）：已垫 N · 还差 M 抽 + 0–80 刻度
- [ ] 角色系引线标注当前处于小保底还是大保底（上个五星歪了 → 下个必 UP）；武器系显示「没有 50/50，出货即 UP」说明
- [ ] 高光时刻纪念牌：旅途总览（总抽数/五星数）、最欧「出手如电」、最非「漫长等待」、大保底就绪状态
- [ ] 无对应数据的空态处理（如某池尚无记录、档案为空）
