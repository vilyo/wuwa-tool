# 08: 五星编年史名册

**What to build:** 主画面成为一本档案：时间倒序的五星卡片网格名册（ADR-0007），每张卡片一眼读全——头像、名字、属性/武器类型、出货抽数大数字 + 0–80 微条、歪/UP 徽章、日期；UP 卡暖色洗底、歪卡冷灰压暗，程度极端的卡片自动跳出来；点击/键盘选中后底部详情条展示完整信息。视觉与交互以定稿原型 `docs/prototype/index.html` 为最终基准，实现与原型冲突时先怀疑实现。

**Blocked by:** 06 头像资产与常驻名单数据、07 统计评语核心。

**Status:** ready-for-human

- [ ] 时间倒序卡片网格名册，最新在前；卡片含头像（缺图回退字牌）、名字、属性/武器类型小标、出货抽数大数字 + 0–80 微条、歪/UP 徽章、日期
- [ ] UP 卡：强调色温洗底 + 顶边 + 实心徽章；歪卡：冷灰底、角色名压暗——扫一眼能数出几个 UP 几个歪
- [ ] 出货数字与微条按程度着色：≤20 绿、≥70 红、其余中性；角色系微条带 62 抽期望参考线（社区口径标注），武器系不显示
- [ ] 名册头部汇总芯片：UP n · 歪 n · 超欧 n · 超非 n
- [ ] 常驻池特例：出货抽数超过 80 时微条按实际长度显示、重复五星标「重复」章
- [ ] 50+ 个五星时换行流畅、名册内部滚动
- [ ] 点击/键盘选中卡片后底部详情条展示该五星完整信息；卡片可达且焦点可见
- [ ] UI 组件测试以种子数据驱动（Vitest + Vue Test Utils），只断言用户可见行为：渲染、选中、详情条联动
