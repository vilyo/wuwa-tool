# 02: 粘贴链接导入端到端（单池曳光弹）

**What to build:** 玩家粘贴一条唤取链接，应用解析出全部参数、识别国服/国际服，拉取**单个卡池**的全量历史，合并去重后事务化写入本地 SQLite，并在一个极简流水列表里看到记录；重启应用数据仍在，重复粘贴不产生重复记录。这是打通「解析 → 官方请求 → 落库 → 展示」整条链的第一颗曳光弹（全池编排见 #03，一键获取见 #04，正式记录抽屉见 #11）。

**Blocked by:** 01 应用骨架与设计基底。

**Status:** ready-for-human

- [ ] 粘贴完整唤取 URL 后解析出全部 9 个参数；按 URL host 或 svr_area 判定国服/国际服
- [ ] 经 Rust 侧带自定义 Referer 的请求按卡池拉取全量历史（无分页、时间倒序）；禁止按 API 返回的中文池名做字符串匹配
- [ ] 记录按 `time + name + qualityLevel + cardPoolType` 组合键去重后**事务化**写入 SQLite；同步中途崩溃不留半写状态
- [ ] 重复导入幂等：同一链接粘贴多次不产生重复数据；只增不减
- [ ] 重启应用后数据完整可读（持久化生效）
- [ ] `code != 0` 一律判定为抽卡链接失效：明确告知并引导「重新打开游戏内唤取记录页后重试」，不当作网络错误重试
- [ ] 一个极简全量流水列表可见（验证展示链路即可）
- [ ] 领域核心以伪造端口（官方 API 端口/存储端口/时钟）单测：参数解析、单池拉取编排、合并去重幂等与只增不减、链接失效判定——不发真实网络请求
