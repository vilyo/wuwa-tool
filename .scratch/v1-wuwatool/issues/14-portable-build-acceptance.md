# 14: 便携版打包与 V1 真机验收

**What to build:** 交付可分发的便携版 zip 并完成 V1 验收：Windows 10/11 x64 上解压到任意文件夹、双击即用、不写注册表、不做安装；升级时替换程序文件夹而档案数据不丢。随后按 PRD DoD 在真机完成人工验收（国服 + 国际服真实账号、抓包隐私验证、大数据量性能、备份往返），发现的问题回灌 issue。

**Blocked by:** 01–13 全部前序票。

**Status:** ready-for-agent

- [ ] 仅便携版 zip（ADR-0008）：解压即用、无安装器、不写注册表；产物体积 ≤ 15MB
- [ ] 升级场景：替换程序文件夹后档案数据完整保留（数据在用户数据目录，与程序目录分离）
- [ ] Windows 10/11 x64 产物可直接运行；应用名与图标按「唤取档案」定名
- [ ] 真机验收（人工，按 PRD §11 DoD）：
  - [ ] 国服 + 国际服真实账号各完成一次一键获取成功
  - [ ] 新版 XOR 混淆日志真机提取成功
  - [ ] 抓包确认除官方 gacha 接口外零网络请求
  - [ ] 1 万 / 2 万条记录下名册与记录抽屉流畅
  - [ ] 备份导出 → 导入往返一致
  - [ ] 「减少动态效果」系统开关生效
- [ ] 验收发现的问题逐条回灌 `.scratch/v1-huanqu-archive/issues/` 新票
