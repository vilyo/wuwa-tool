# 06: 头像资产与常驻名单数据

**What to build:** 名册卡片要能显示角色头像与武器图标：把开源素材仓库的头像/武器图标在构建期打包进应用，建立 `resourceId → 文件名` 映射，缺图时回退为属性色菱形 + 名字首字字牌。同时把「常驻名单」（歪判定的依据，ADR-0002）做成随应用分发的数据文件。本票不依赖获取管线，可与 #02/#03 并行。

**Blocked by:** 01 应用骨架与设计基底（构建与打包约定）。

**Status:** ready-for-agent

- [ ] 头像与武器图标自 ryanbenson/wuthering-waves-assets 构建期打包（ADR-0005），许可文件随附；仅面向离线使用
- [ ] `resourceId → 文件名` 映射表建立并在运行时加载；缺图回退：属性色菱形 + 名字首字字牌
- [ ] 常驻名单数据文件随应用分发（ADR-0002）：名单内五星判为「歪」、名单外判为当期 UP
- [ ] 名单内物品均有对应图标（映射覆盖测试）；未知物品可标「未知」且不计入歪率（消费方为 #07）
- [ ] 资产打包后应用体积增量可控（目标整体 ≤ 15MB 的约束在 #14 验收）
