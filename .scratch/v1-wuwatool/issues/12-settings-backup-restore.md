# 12: 设置弹窗与备份恢复/清空

**What to build:** 数据安全掌握在自己手里：设置弹窗（焦点往返、ESC 关闭）里可以导出全部记录为 JSON、导入恢复（按同一去重键合并、往返一致），以及用二次确认清空当前档案。档案数据存 Windows 用户数据目录、与程序目录分离——替换程序文件夹不丢数据。断网时备份/恢复全部可用。

**Blocked by:** 02 粘贴链接导入端到端（有数据可备份）。

**Status:** ready-for-human

- [ ] 设置弹窗打开/关闭：焦点往返、ESC 关闭
- [ ] 导出全部记录为 JSON 文件
- [ ] 导入恢复：按 `time + name + qualityLevel + cardPoolType` 同一去重键合并；导出 → 导入 → 再导出结果一致（往返一致测试）
- [ ] 「清空数据」删除当前档案前二次确认
- [ ] 档案数据位于 Windows 用户数据目录、与程序目录分离（ADR-0008）
- [ ] 断网环境下备份/恢复/浏览全部可用（零网络依赖验证）
