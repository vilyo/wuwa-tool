# 11: 记录抽屉

**What to build:** 想查账时不离开主画面：从顶栏呼出右侧抽屉，浏览全量流水（时间、池、物品、稀有度着色），可按稀有度芯片与卡池下拉筛选；2 万条流水虚拟滚动依然流畅。本票只依赖 #02 的数据，可提前并行。

**Blocked by:** 02 粘贴链接导入端到端（单池曳光弹）。

**Status:** ready-for-human

- [ ] 顶栏呼出右侧抽屉，浏览当前档案全量流水：时间、所属池、物品名、按稀有度着色
- [ ] 按稀有度芯片与卡池下拉筛选；筛选结果为空时提供「清除筛选」
- [ ] 虚拟滚动：2 万条流水滚动流畅（以种子数据验证）
- [ ] 浮层无障碍：焦点往返、ESC 关闭
- [ ] 组件测试以种子数据驱动：渲染、筛选、空态、ESC
