# 03: 全池同步编排与进度

**What to build:** 触发同步（手动粘贴入口复用同一管线）后，应用对全部卡池逐池串行拉取：界面显示「正在获取 卡池 x/13」进度；限速、超时、重试齐备；某池返回 `code != 0` 时整体进入链接失效引导而不是反复报错；官方新增的未知卡池 code 记录落入「未知池」数据兜底，应用不崩坏；完成后提示新记录约 30 分钟延迟。

**Blocked by:** 02 粘贴链接导入端到端（单池曳光弹）。

**Status:** ready-for-human

- [ ] 逐池串行请求全部已知卡池 code（1..=13 开放式枚举）；相邻请求间隔默认 1s（下限 600ms）
- [ ] 单请求超时 15s；失败重试 3 次（网络类失败）；限速与重试经假时钟端口测试
- [ ] 同步过程可见「正在获取 卡池 x/13」进度，同步完成有结果反馈
- [ ] 任一池 `code != 0`：停止后续请求，进入「重新打开游戏内唤取记录页后重试」引导，不重试、不误报网络错误
- [ ] 未知卡池 code 的记录落「未知池」数据（浅统计），界面与存储均不崩坏
- [ ] 同步完成提示：新记录约 30 分钟延迟、刚抽完查不到是预期行为
- [ ] 手动粘贴与后续一键获取（#04）共用这一条编排管线
