# 13: 偏好设置：主题 / 自动同步 / 目录管理

**What to build:** 日常使用零操作的最后一环：设置弹窗中可切换明暗主题（明色默认、选择被记住）；「启动时自动同步」开关（默认开）——启动时仅当链接有效才静默增量同步，不打扰；可重新探测 / 查看当前游戏安装目录，换了安装位置能自愈。

**Blocked by:** 12 设置弹窗与备份恢复/清空（弹窗壳就位）、03 全池同步编排与进度（自动同步复用管线）、04 目录探测与一键同步（探测逻辑）。

**Status:** ready-for-human

- [ ] 明暗主题切换，明色为默认；偏好持久化、重启后保持（tokens 基底在 #01）
- [ ] 「启动时自动同步」开关默认开：启动时仅当链接有效时静默增量同步；失效时不弹错误打扰（状态栏可提示需要重新获取）
- [ ] 重新探测 / 查看当前安装目录入口（复用 #04 探测链与手动指定）
- [ ] 三项偏好的状态在设置弹窗中即时可见、即时生效
