# 设计系统 · 「游戏原生档案」（v11 终稿，2026-09-26）

鸣潮唤取记录统计助手的视觉语言规范。信息架构见 ADR-0003（单画面编年史 + 抽屉/弹窗），视觉母语见 ADR-0004（游戏原生），配色终稿见 ADR-0006（**强调色随主题**：明色用共鸣青、暗色用低饱和金；低饱和金另贯穿两主题承担五星/评级/荣誉）。

## 设计原则

1. **属于游戏家族**：采用鸣潮游戏内 UI 的母语——中性灰白/炭黑面板、鎏金细线、平行四边形斜切、菱形符号、黑色标题条。
2. **是窗口，不是网页**：满视口构成、无页面滚动。结构固定为：标题栏 → 池标签行 → 左主画面（五星编年史名册）+ 右信息栏（保底引线、高光时刻）→ 状态栏；仅名册与信息栏内部滚动。
3. **每色一职 + 面积纪律**：强调色（明 = 共鸣青 / 暗 = 低饱和金）= 界面操作、选中、引线、进行中、UP 卡；金 = 五星、评级、荣誉（贯穿两主题的小面积）；绿/红 = 欧非程度；紫/蓝 = 四星/三星。强调色不与稀有度色混用。
4. **动效回答动作**：悬停反馈、选中环、进行中呼吸点；`prefers-reduced-motion` 全关。

## 字体

- **中文**：系统黑体栈（PingFang SC / Microsoft YaHei / Noto Sans SC）；标题 700 + 0.14em 字距。
- **数字**：Barlow Semi Condensed 500–700，`tabular-nums`。

## 形状词汇

- **斜切**：`skewX(-10deg)` 用于池标签、主按钮、徽章；内容反向回正。
- **菱形**：品牌符、项目符、评级章（34px）、引线滑块、稀有度点、头像字牌水印。
- **黑条**：标题栏、抽屉/弹窗头、激活池标签用 `--ink` 黑底。
- **强调顶线**：主面板顶部 2px 强调色渐隐线。

## 关键组件

- **五星编年史名册**：时间倒序卡片网格（min 170px，auto-fill 换行，容器内部滚动，50+ 条天然扩展）。卡片含 **42px 头像位**（真实角色/武器图标，来源与映射见 ADR-0005，`<img>` 缺图回退属性色菱形 + 名字首字字牌）。**三层视觉编码，状态优先**：①结局——UP = 强调色温洗底 + 顶边 + 实心徽章，歪 = 冷灰洗底 + 灰顶边 + 实心灰章（歪卡角色名转灰）；②程度——出货大数字与 0–80 微条：超欧 ≤20 抽 = 绿、超非 ≥70 抽 = 红、正常中性；③属性——头像旁小菱点 + 小字。名册头部汇总芯片（UP n / 歪 n / 超欧 n / 超非 n）实时计算；「进行中」卡强调色虚线框置顶。
- **评级菱章**：34px 菱形描边（低饱和金，贯穿两主题）+ 字母（S / A / B+ / B / C / D，对应评语档位见 PRD F3）。
- **保底引线**（右栏）：强调色细轨 + 菱形滑块 + 刻度；「已垫 N · 还差 M 抽」。
- **高光时刻**（右栏）：强调色菱项目符（漫长等待为灰菱）。
- **状态栏**：32px 细行——延迟提示、6 个月窗口说明、本地隐私声明、版本号。
- **浮层**：记录抽屉（右滑 580px，黑头）/ 设置弹窗；开关焦点往返，ESC 关闭。

## 交付前检查（每次改版必跑）

双主题文字对比 ≥4.5:1；键盘可达（卡片可点击/选中）；焦点可见（强调色 2px outline）；`prefers-reduced-motion` 关闭全部动画；无 emoji 图标；按压态不位移布局（`scale` 除外）；浮层焦点管理；满视口无页面滚动（≥1080px 宽）。
