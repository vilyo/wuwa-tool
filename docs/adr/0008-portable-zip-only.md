# 0008 分发形态：仅便携版 zip，解压即用（放弃 NSIS 安装包）

原 PRD 决策 A4 为「NSIS 安装包 + 便携版 zip 双形态」。2026-09-26 用户拍板改为**仅便携版 zip**：下载、解压到任意文件夹、双击运行，不做安装包。

## 决定理由

1. 目标用户是单人使用的本地工具玩家，安装器不带来价值（无系统服务、无文件关联、无多用户配置），只带来步骤。
2. 免安装降低尝试门槛：不想要的用户删掉文件夹即完成「卸载」。
3. 避开安装器的维护成本（卸载项、开始菜单快捷方式、安装目录选择），也简化 CI 打包链路（GitHub Actions `windows-latest` 上 `tauri build` 产出 zip 即为成品）。
4. 包体积目标（≤15MB）不变，便携 zip 与 NSIS 体积相当。

## Consequences

- **没有开始菜单快捷方式与系统卸载项**：用户以文件夹为单位管理软件；帮助文案需说明「删除文件夹即卸载」。
- **档案数据与程序目录分离**：记录与设置仍存放在 Windows 用户数据目录（Tauri 默认 app data 目录，即 `%APPDATA%` 下），而非 exe 旁边。这是有意的：升级 = 下载新 zip 替换程序文件夹，档案数据原地保留、不受影响；跨机迁移走设置内 JSON 备份/导出。曾考虑「数据放程序目录旁」的纯便携方案，因替换升级会连带数据、且多程序副本会互相看不到档案而放弃。
- **未签名 exe 的首次运行提示**：无代码签名证书（V1），zip 经浏览器下载后带 Mark-of-the-Web，首次运行可能触发 Windows SmartScreen 提示；需在帮助/诊断文案中给出「右键 → 属性 → 解除锁定」或「更多信息 → 仍要运行」的指引。
- V1 无自动更新（沿袭原 A4），升级方式即上述「替换文件夹」。
- ADR-0001 中「安装包 ~10MB」的表述按本 ADR 理解为「便携版成品 ~10MB」。
