# 0004 视觉语言改定：游戏原生 UI 母语（象牙白 / 鎏金 / 斜切 / 菱形）

前三版原型（四页签仪表盘 → 黑金 HUD 终端）连续被否：前者像管理软件，后者仍属「外部工具贴皮」的网页观感，且用户明确指出这是 **C/S 桌面软件**——需要满视口窗口构成、而非可滚动网页页。

决定：
1. **视觉母语改用鸣潮游戏内 UI 的设计语言**——象牙白面板、鎏金细线、平行四边形斜切标签、菱形符号、黑色标题条；让软件看起来属于游戏家族，而非第三方网页工具。
2. **形态按桌面客户端组织**：满视口、无页面滚动；标题栏 / 池标签行 / 左主画面（共鸣曲线）+ 右信息栏（保底引线、高光时刻）/ 底部状态栏。
3. **默认主题改为明色（象牙白）**，与游戏内界面同源；暗色保留为夜晚模式。此项覆盖 PRD 早先「暗色默认」的假设。
4. 编年史图表由 HUD 柱状改为**共鸣曲线**（细金折线 + 菱形标记，虚线段 + 空心菱形表示进行中）。

## Considered Options

- 黑金 HUD 终端（被否）：与市面游戏工具同质，且是网页式排版。
- 沿用暗色默认（被覆盖）：游戏最具辨识度的菜单界面是象牙白底 + 金，明色更贴近母语。

## Consequences

- docs/design/DESIGN-SYSTEM.md 全量重写为 v4 规范，v3 HUD 规范作废。
- 展示字体弃用黄油体与 Chakra Petch，改为系统黑体加重字距 + Barlow Semi Condensed（数字）。

> 更新（2026-09-26）：本决定第 4 点「共鸣曲线」已被 [ADR-0007](./0007-chronicle-roster-grid.md) 取代（五星编年史名册卡片网格），第 2 点中的「左主画面（共鸣曲线）」同样以名册为准；第 1–3 点的母语、形态与明色默认仍然有效，配色终稿另见 ADR-0006。
