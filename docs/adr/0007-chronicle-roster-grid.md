# 0007 编年史呈现定稿：五星编年史名册卡片网格（取代共鸣曲线）

> 本 ADR 为**追溯记录**（2026-09-26 固化）：设计系统从 v4 演进到 v11 的原型迭代中，编年史的呈现形态已从 ADR-0004 第 4 点确定的「共鸣曲线」变为「五星编年史名册卡片网格」，并在定稿原型 `docs/prototype/index.html` 中实现完毕，但当时未留下决策记录，特此补记。

ADR-0004 曾将编年史定为「共鸣曲线」（细金折线 + 菱形标记，虚线段 + 空心菱形表示进行中）。后续迭代改为**时间倒序的五星卡片网格名册**：每张卡片承载头像位、角色名、属性/武器类型小标、出货抽数（大号数字 + 0–80 微型进度条）、歪/UP 徽章与日期，首位为虚线「进行中」卡；点击/键盘选中卡片后由主画面底部的**详情条**展示完整信息。

## 决定理由

1. **头像资产只有卡片能承载**（ADR-0005）：曲线上的数据点放不下 42px 头像，只能标名字，「一眼认出自己抽到的角色」这一核心诉求无法达成。
2. **三层视觉编码需要面，不需要线**：结局（UP/歪）、程度（超欧/超非）、属性三类信息在卡片上可并行呈现（底色温洗/顶边/徽章 + 数字与微条着色 + 角标），曲线上只能编码一维。
3. **长线可扩展性**：名册为网格自动换行 + 容器内部滚动，原型已用确定性伪随机 52 个五星的模拟长线验证；曲线在长线下一屏放不下，只能缩放或滚动丢失全局。
4. **隐喻贴合**：「档案 / 名册」与产品工作名「唤取档案」同族，卡片编年史即「这本档案的正文」。

## Consequences

- DESIGN-SYSTEM v11 以名册规范为准；「声波图 / 共鸣曲线 / 波峰」等词汇全部作废，相关文档已清理。
- 交互从「点击波峰看详情」改为「卡片选中 + 详情条」（ADR-0003 的单画面 IA 与抽屉/弹窗结构不变）。
- V1 不再需要任何图表库（微型进度条与保底刻度均为 CSS 实现），ECharts 从依赖中移除；若 V2 引入分布直方图再重新评估。
