# 信息架构：无导航的单画面编年史 + 抽屉/弹窗

V1 原型最初采用「总览 / 卡池 / 记录 / 设置」四页签 + 侧边导航的信息架构，评审反馈「像管理软件，不像抽卡统计助手」：导航、表格与指标卡占掉了产品注意力，而抽卡工具真正要突出的是**五星事件序列与欧非叙事**。

决定：取消常驻导航。主画面为单屏「声波编年史」（欧非评语 + 五星声波时间轴 + 保底引线 + 高光时刻纪念牌），卡池切换用顶部筛选 chips；记录改为右侧抽屉、设置改为弹窗，均从顶栏呼出。

## Considered Options

- **四页签 + 侧边导航（被否）**：信息分区清晰，但拓扑本身即管理软件形态，叙事内容被稀释。
- **保留卡池独立页（被否）**：池分析已由「声波图 + 汇总行 + 波峰详情」承担，独立成页只增加导航层级。

## Consequences

- 表格型需求（全量流水）多一次点击（顶栏呼出抽屉）。
- 抽屉/弹窗需要焦点管理与 ESC 关闭；正式版（Tauri）沿用 Web overlay 实现，不新增窗口。
- 出货分布直方图不再单独成页，由编年史主画面与记录抽屉承担。

> 更新（2026-09-26）：本文的「声波编年史 / 声波图 / 波峰」在后续迭代中定稿为**五星编年史名册卡片网格**，见 [ADR-0007](./0007-chronicle-roster-grid.md)；单画面 + 抽屉/弹窗的信息架构本身不变。
