# 「歪」的判定口径：常驻五星名单反向判定

判定限定池五星是否为当期 UP，有两种口径：内置**版本卡池日历**（按抽卡时间对照当期 UP，精确但每个版本必须更新数据，断更即判错），或**常驻五星名单反向判定**（抽到常驻名单内的五星 = 歪，名单外 = 当期 UP）。

V1 选后者：维护成本低——仅在官方将角色并入常驻池时更新名单，名单作为随应用更新的数据文件。前提口径：**武器精准调频无 50/50、五星必为 UP**，歪率仅对角色限定池计算。

## Consequences

- 无法区分「当期 UP」与「复刻池非当期但非常驻」等极端情况（鸣潮现行机制下不存在此类情况，机制变更时需 revisit）。
- V2 引入按版本统计时，再补版本卡池日历并回填历史判定。
